# This folder contains force field parameters from different sources.


### uff_atomic_data_Claude_transcribed.csv 
Original UFF parameters LLM-transcribed from Table I "Atomic Data" in "Rappe, A. K., Casewit, C. J., Colwell, K. S., Goddard, W. A. I. & Skiff, W. M. UFF, a full periodic table force field for molecular mechanics and molecular dynamics simulations. J. Am. Chem. Soc. 114, 10024–10035 (1992)."


### dreiding_vdw_parameters_Claude_transcribed.csv
Original DREIDING parameters LLM-transcribed from Table II "The van der Waals Parameters for DREIDING" in "1.  Mayo, S. L., Olafson, B. D. & Goddard, W. A. DREIDING:  a generic force field for molecular simulations. J. Phys. Chem. 94, 8897–8909 (1990)."


### force_field_mixing_rules.def
RASPA2 example data copied from ~/RASPA/simulations/share/raspa/forcefield/ExampleMOFsForceField/force_field_mixing_rules.def 


### UFF_vincent_2025.dat
UFF parameter Vincent Dufour-Decieux used in "1.  Dufour-Décieux, V. et al. Classical density functional theory as a fast and accurate method for adsorption property prediction of porous materials. AIChE Journal e18779 (2025) doi:10.1002/aic.18779.". 

(file from https://gitlab.ethz.ch/epse/molecular-design-public/paper-3d_dft -> Data/Forcefield/UFF.dat)


### force_field_wei_July_2026.template
UFF and DREIDING parameters used by Wei for some GCMC simulations (with RASPA3) in July 2026.
